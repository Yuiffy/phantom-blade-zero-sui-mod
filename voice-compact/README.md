# 岁己战斗语音 v5：直接安装候选

**测试候选，离线核验通过，游戏实测待反馈。** 仅适配 Steam app 4115450、build 26367565。成年魂战斗声音，适用于成年魂不同服装；不处理少年魂或剧情对白。模型独立安装。

## 安装（不需要 Python）

1. 完全退出游戏。
2. 移走本项目旧版语音三件套，例如 `z_Sui_Hun_NaturalVoice_Reviewed_v4_P.*`，存到游戏目录外备份。保留模型文件，不要清空 `~mods`。
3. 把本 ZIP 的 `mod/` 内三个同名文件复制到：

```text
<PBZ游戏目录>/ProjectPBZ/Content/Paks/~mods/
```

三个文件名都是 `z_Sui_Hun_NaturalVoice_Compact_v5_P`，扩展名分别为 `.pak`、`.utoc`、`.ucas`。直接使用，不需要 Python、脚本、UE、密钥、Oodle 或本地重建。

重启游戏，手动检查轻击、跳攻、不同武器、受击及快速连续出招。中文和英语的静态映射都已覆盖，但不代表双语游戏测试已通过。不要与覆盖同一声音事件的语音 MOD 同时使用。

## 内容与大小

三件套合计 **3,290,077 字节（约 3.29 MB）**，ZIP 下载约 **729 KB**。复用二审 v4 全部 **21 段录音**，独立 WEM 合计 164,334 字节，覆盖 474 个语言/媒体槽（中文 238、英语 236）。原 27 个事件加一个共享媒体关联事件，共 28 个资产；部分声音需在不同资源里重复存储，所以容器大于去重音频大小。

没有减少已选声音，没有 TTS、新编码、时间拉伸或按原声音长度强裁；声音字节与已审 v4 一致。与 234 KB 的 v4 本地重建补丁不同，这里的三件套本身就只有约 3.29 MB。没有完整 VO_CN/VO_EN 库或原版语音，只有必要的修改后事件/bank 元数据和选定岁己声音。

较长选音的衔接、截断/重叠，以及新 hash 加载方式的实际听感仍需游戏测试。离线核验不能证明运行成功。

## 卸载与回退

退出游戏，只移走这三个 `z_Sui_Hun_NaturalVoice_Compact_v5_P` 文件。需要恢复旧语音时，把之前备份的旧语音三件套放回；不要把两版叠装。存档、语言设置和模型不需要修改。

精确大小/哈希见同包 `manifest.json`，选音来源见 `audio-provenance.json`。技术依据、范围和源码推断边界见仓库的 [制作案例](https://github.com/Yuiffy/phantom-blade-zero-sui-mod/blob/main/skills/pbz-character-mod/references/voice-compact-case.md)；制作脚本仅供维护者，普通玩家无需运行。
