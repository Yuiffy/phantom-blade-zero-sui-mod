岁己 JK 外套侧马尾 ＋ 地雷系双马尾 · 双皮肤 v1.0.0

同一个 MOD 包包含两套成年魂角色替换：
  黑伤（逃亡） → JK 外套侧马尾，JK Motion v5
  黑伤 → 地雷系双马尾，无翅膀，Jirai R5
黑伤内部无帽变体也使用地雷系；不处理少年魂，不修改服装解锁条件。
验证游戏：Steam app 4115450 / build 26367565。

安装（不需要 Python 或 UE）：
1. 退出游戏，先备份并移出本项目旧模型三件套（包括旧独立 JK、旧地雷系或旧双服装包）。独立语音包可保留。
2. 将 mod/ 内 z_Sui_DualOutfit_JK5_JiraiR5_P 的 .pak、.utoc、.ucas 三个文件一起放入：
   <PBZ游戏目录>/ProjectPBZ/Content/Paks/~mods/
   没有 ~mods 目录可自行新建。
3. 在游戏内选择对应服装。只需安装这一套三件套，无需分别安装两个模型。

本包使用同一份合并外观表，不要与旧模型、其他修改同一外观表的 MOD 叠装。
卸载时退出游戏，只移除本包同名三个文件；需要回退时放回自己备份的旧包。
不包含语音，已安装的独立 Compact v5 语音可以继续使用。

本版收录 JK 不透明安全裤覆盖、立体白猫挂饰与加强衣服碰撞避让；地雷系包含比例、手部、肩袖修正与双马尾、裙摆物理。
最终容器、骨架、蒙皮/布料映射、材质依赖、两个服装选择链及已安装哈希均已核验。
用户对当前安装版反馈“不错”并批准双皮肤发布；所有武器、动作、过场及长时间稳定性尚未逐项验证。
离线合成动作与预览不能代表所有实际游戏动作，也不能保证所有动作无穿模。
previews/ 是离线 Blender 预览，不是游戏截图。

可选 Python 3.10+ 文件验证：
  python scripts/mod_files.py verify --manifest manifest.json
可选安装工具默认只预览，加 --apply 才写入；必须先按以上说明移出旧模型包。

文件校验见 manifest.json。模型、角色、贴图与游戏派生数据不适用代码 MIT 许可，详见 NOTICE.md。
