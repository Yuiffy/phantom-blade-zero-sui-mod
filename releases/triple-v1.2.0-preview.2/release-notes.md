# 岁己三皮肤＋战斗语音 v1.2.0-preview.2

适用《影之刃零》Steam build **26367565**。一个 ZIP 包含三套成年魂外观和 Compact v5 战斗语音。

| 游戏内外观 | 皮肤 |
| --- | --- |
| 黑伤（逃亡） | JK 外套侧马尾，含当前裙装修复 |
| 黑伤 | 地雷系双马尾 |
| 故友 | 小粉帽 JK v0.4.11-preview.1 |

小粉帽校正了白袖和灰色背心的串色，补回原画上的两列浅灰菱格，修整了双腕接缝、抬手时的衣身绑定和下摆轮廓，并沿拉齐后的下缘重绘双白纹。

下载 **Sui_TripleOutfit_WithVoice_PBZ_v1.2.0-preview.2.zip**。完全退出游戏，备份并移出旧岁己模型、语音和覆盖补丁，再把 mod/ 内的 **42 个文件**复制到 ProjectPBZ/Content/Paks/~mods/。进入「角色 → 外观」切换服装。

已从最终 ZIP 核对三套外观、28 个战斗语音事件和 223 份有效资源载荷。整包仍处于预发行阶段，游戏内完整流程待实测。小粉帽的离线深蹲预览中，裙腰可能露出少量浅色衬层。
