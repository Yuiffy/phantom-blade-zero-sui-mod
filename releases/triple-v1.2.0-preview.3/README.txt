岁己三皮肤＋战斗语音 · v1.2.0-preview.3

适用《影之刃零》Steam build 26367565。整合包包含三套成年魂外观和 Compact v5 战斗语音。小粉帽采用 v0.4.11-preview.1，含服装修色、双腕接缝和下摆双白纹修整。JK 和小粉帽均加入原生裙骨绑定，小粉帽的裙腰恢复深蓝布色。

安装

1. 完全退出游戏。
2. 备份并移出旧版岁己模型、语音和另装的岁己覆盖补丁。
3. 把 ZIP 内 mod/ 下的全部 42 个文件复制到以下目录，保留原文件名。若 ~mods 文件夹不存在，可自行新建。
   <游戏安装目录>/ProjectPBZ/Content/Paks/~mods/

游戏内怎么换装

打开角色装备栏，按手柄 RT 切到「外观」，选择对应服装。

  黑伤（逃亡） → JK 外套侧马尾
  黑伤         → 地雷系双马尾
  故友         → 小粉帽 JK

游戏对「故友」的提示是“达成任意结局后解锁”。服装攻略记载，在庞镇击败「长鸿：雷电枪骑」后，「故友」会加入衣柜。
https://metabot.gg/zh_CN/phantom-blade-zero/outfits#kindred

想让岁己替换别的服装？在 Codex 中打开项目仓库，告诉它要改的岁己模型、目标服装和游戏版本。比如“把小粉帽 JK 改成替换风雪”。
https://github.com/Yuiffy/phantom-blade-zero-sui-mod

卸载时先退出游戏，按 bundle-manifest.json 的清单移出本包文件。要回退到旧版，再放回备份。
