# 岁己三皮肤＋战斗语音 v1.2.0-preview.3

适用《影之刃零》Steam build **26367565**。一个 ZIP 包含三套成年魂外观和 Compact v5 战斗语音。

| 游戏内外观 | 皮肤 |
| --- | --- |
| 黑伤（逃亡） | JK 外套侧马尾，加入原生裙骨绑定 |
| 黑伤 | 地雷系双马尾 |
| 故友 | 小粉帽 JK，加入原生裙骨绑定并修复裙腰串色 |

JK 和小粉帽各使用成年魂现有的 16 根裙骨。裙骨版已经过试玩反馈。小粉帽修正裙腰的纹理采样，去除灰蓝色块，保留下摆白纹。

下载 **Sui_TripleOutfit_WithVoice_PBZ_v1.2.0-preview.3.zip**。完全退出游戏，备份并移出旧岁己模型、语音和覆盖补丁，再把 mod/ 内的 **42 个文件**复制到 ProjectPBZ/Content/Paks/~mods/。进入「角色 → 外观」切换服装。

修色已检查站姿正面、侧面、背面和抬腿预览。最终 ZIP 已核对三套外观、28 个战斗语音事件和 223 份有效资源载荷。修色整包待游戏内复测。
