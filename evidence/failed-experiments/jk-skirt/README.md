# JK 裙摆实机未通过的实验

以下记录对应《影之刃零》Steam build 26367565 的 JK「黑伤（逃亡）」。三合一 v1.2.0-preview.1 中生效的裙摆版本为 StableSkirt1。[三合一预发行版](https://github.com/Yuiffy/phantom-blade-zero-sui-mod/releases/tag/triple-v1.2.0-preview.1)

| 实验版 | 改动 | 实机观察 |
| --- | --- | --- |
| Drape1 | 收回向前支出的裙摆，调整裙摆随腿移动 | 跑完停下后，裙摆仍不自然地隆起，下垂效果和前一版接近。 |
| Pleats1 | 放低两侧裙边，收窄外套下方鼓出的一圈 | 整体穿模有改善，前腰仍有串色，后摆略鼓。跑步时左右裙片随臀腿摆动，观感像裤子。 |
| Gait1 | 修前腰串色，收后摆，减弱两侧裙片随同侧大腿移动的幅度 | 2026-11-21 的战斗站姿实测中，两侧大腿仍会从后裙摆穿出。 |

三个版本均完成了六组走路、跑步、下蹲的离线回放。Gait1 的战斗站姿问题应作为单独的回归用例检查。试玩时生效的 Gait1 通过成品身体载荷哈希确认。

归档清单记录各版三件套的文件名、大小和 SHA-256，以及独立读回的身体载荷哈希。可安装容器保存在本地实验归档。[归档清单](manifest.json)
