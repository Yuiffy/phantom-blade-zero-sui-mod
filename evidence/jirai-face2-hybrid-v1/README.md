# Face2 + Face3 组合证据

按用户明确要求恢复 Face2 脸部、眼眶、眉睫毛、嘴型与皮肤图集，瞳孔/虹膜和闭合眼白保留 Face3。嘴部只调整局部着色切线帧，原位置、拓扑、UV 和嘴唇颜色不变；不重画嘴线。上一轮 Polish1 眼睛已获用户负面实机反馈，封锁重新安装。

`geometry-verification.json` 对成品读回逐项核验指定来源：Face2 眼眶与嘴型、Face3 两种眼部材质表面、保留的光环/袖内补面、四圈接缝和其他材料。`verification.json` 记录三 package 白名单、独立 native/材质/VT 读回、原生骨架/布料保护及 67 个臂部权重副本。`atlas-report.json` 说明仅在原 Skin UV 未占用区域增加臂部肤色小块；全部原脸部与嘴部采样像素保持 Face2 原样。

`installation.json` 记录移出被否定 Polish1 三件套，安装本轮新三件套，并保持其余十八文件原哈希。实际安装集合重新挂载并提取载荷读回；其余 102 个有效 package 的 metadata 保持。`visual-review.json` 仅收录七视角预览的哈希和检查范围，最终读回渲染像素与已审阅图一致。

原图集、参考、源资产、派生预览与容器只留本地忽略目录。离线预览使用源 PNG，不复现原生 shader、cooked VT 采样或游戏灯光。本组合已安装，游戏内观感和动态效果尚待用户复试；不能把离线检查记成用户认可。没有提交或推送远端，也没有更新 Release。
