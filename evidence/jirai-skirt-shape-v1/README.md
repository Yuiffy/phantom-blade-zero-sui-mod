# 地雷岁 R8 裙型修整证据

状态以 `result.json` 为准。参考用户原立绘与生成四视图，撤回 R7 下半截 4 cm 外扩，收拢并压低外翘裙缘。尺寸与公式见 `selected-parameters.json`；最终可见混合上限为 35%，见 `render-settings.json`。首轮 40% 候选未通过 3 cm 局部回落门槛，失败报告保留为 `rejected-blend40-recovery.json`，该候选未安装。`shape-comparison.png` 使用同机位、同尺度的旧/新静态几何和新候选求解站定表面。

裙面与 cage 改形后重新导入、绑定并实际连续求解；六组走停/跑停/蹲起检查使用三动作、30/60 Hz 与各三轮动作后站定。本目录结论来自新容器量化映射，沿用 Recovery1 的下摆顶点集合及原门槛，未用缩裙后重新筛选的高度段排除难测顶点。

所有预览为离线 Blender 渲染，不是游戏截图。裆部连通不透明安全裤、身体、骨架、头发参数保留；仅裙子与导向几何变化。保留深动作穿裙统计，不声称全动作无穿模。Face2 独立补丁按两种目录顺序检查挂载，安装后再读回。用户实机复测尚待反馈。许可边界见根目录 NOTICE.md。
