# 地雷岁 R6 细节修复证据

2026-11-16 安装到“黑伤”；黑伤（逃亡）继续使用原来的 JK Motion v5，语音保持现状。当前安装记录、成品哈希及本地 R5 回退位置见 `summary.json`。新版本尚未进行游戏实测。

本次清理左大腿后侧暗色竖痕、前吊带的旧投影与肉色凸起，重建贴腿黑带及方形金属扣。带子按下方皮肤的实际三角面传递蒙皮，上端止于裙内；扣子具有边框、横梁和扣针。另清理颈部烘焙项圈碎片、恢复非变形 IK 标记。

`r5-before-*` 为修复前的离线渲染；其余 PNG 为 R6 细节版离线渲染。`suspender-crouch.png` 与 `suspender-run.png` 来自最终容器蒙皮和 GPU cloth 映射在作者合成动作中的重建表面，不是游戏截图，也不表示旧版裙子穿模已修好。其他十张静态图覆盖正后左右与吊带/大腿/头发近景。图片哈希与输入来源见 `preview-manifest.json`。

`suspender-fit-audit.json` 检查三种合成动作、19 个采样时刻的两个新增部件，共 114 组。检查的是新增顶点至实际变形后腿面的有符号最近距离；不能据此推断每个三角面、所有游戏动画或像素级绝无穿插。源图集修复保持蒙版外像素不变；最终 VT payload 已核对链路，但未将最终游戏 VT 独立解码为像素。

独立容器读回覆盖 94 个包、两套身体和外观表。JK 的几何/骨架/布料 PA 与其他保留包的数据、全部外观选择行均与此前 JK5+地雷岁 R5 组合一致。地雷岁细节版保留 R5 三组布料、裙摆/头发顶点及权重和八个 cloth 碰撞球。手臂、头颈比例保持 R5。

`physics-research-result.json` 记录额外物理研究失败边界：测试蹲姿的采样接触改善，但跑步和大幅抬手仍有表面穿插。该方案没有安装，也没有被当作本轮细节版的完成结果。IK 标记测试通过仅证明测试动画求值正确，单手握刀效果仍待用户实测。
