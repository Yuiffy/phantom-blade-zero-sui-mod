## 调整

- 肩颈沿用已离线核验的 v3 修正：头与头饰向下 3.5 cm、向后 0.6 cm，连续缩短颈部；肩线局部最高抬升 4 cm、近端袖子补足体积，加入渐变锁骨权重。用户当前看到的 v2 尚不含此修正。
- 书包整体横向缩至 75%，同一中心线收窄包体、侧翼、口袋、提手及附加包带，共 7,311 个顶点。高度、厚度及骨骼权重未改，其余 27,745 个顶点与最终 v5 完全相同。
- 裙摆保留 v5 的较小大腿跟随权重和局部间隙，限制抬腿时过高翻起；增加不透明深色安全内衬（889 顶点、1,670 三角面）。原腿部几何未改，没有新增布料模拟。
- 成品 68,347 三角面、35,056 源顶点、264 骨、9 材质。源网格清理后为 68,347 面，最终 cook 与源一致。

## 验证与限制

- 同镜头比较 v2/v6 静态肩颈、双手前握诊断姿势，以及收窄前后的背面；完整正侧背预览附后。诊断姿势不是游戏动画。
- 肩部继承 v3 抬臂检查；缩短颈部后的部分转头边长指标略增，见 v3-upper-pose-comparison.json，不能声称全部动作均改善。
- 裙摆人工姿势仍有交叉，尤其深蹲和高抬腿。最终 v5（v6 裙子未变）下摆交叉面：待机 0、迈步 4、抬膝 19、大步 0、深蹲 45。该指标不等于可见穿模像素，也不保证实机完全遮挡。
- 独立读回 40 个最终资源，核验材质/VT、骨架、原生 PhysicsAsset/PostProcessAnimBlueprint 引用、外观选择与隐藏部件。
- cooked 62,599 个渲染顶点覆盖全部源顶点；位置最大误差 0.000034571 cm；按安装的 UE 权重量化规则复算后误差为 0。仅 2 个顶点需要考虑相等 uint16 权重的排列顺序，未放宽容差。
- 骨架平移最大误差 0.003062 cm，旋转 0.013160 度。导入仍有 bind pose 重建提示，以上为实际成品读回结果。
- 待实机检查肩部转动、持刀、跑跳和蹲姿；未新增脸部表情、LOD 或头发物理。

## 安装与源文件

仅在游戏退出后使用本机 variants/new-jk-v6/install-verified.ps1。脚本检查游戏进程、build、三件套哈希，备份 v2 后替换，并核对语音和其他文件不变。包不自动安装。
bound .blend/FBX 是最终游戏适配模型；refined-source .blend/preview.glb 是适配前编辑源，未应用此版肩颈、裙摆与窄书包调整。相关变化由 bind_hun.py 与 skirt_lining.py 生成。
脚本依赖本机 PBZ 工作区布局、各版诊断源、合法提取模板和工具，交付不是独立一键构建环境。
代码许可不覆盖角色设计、贴图和派生骨架。原游戏资源、密钥及私人录播不进入源文件交付；含游戏模板的 MOD 容器只留本地。
