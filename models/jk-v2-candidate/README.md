# 岁己 JK v2：比例与蒙皮修正候选

日期：2026-11-15。目标：本机 PBZ build 26367565，成年魂「黑伤（逃亡）」。
状态更新（2026-11-15）：v2 已安装并校验三文件 SHA256，旧 v1 已备份。用户反馈：“腿确实可以，但是裙子和腿有点穿模”。仅记录已反馈范围，其他动作和全场景尚未完成实测。
旧版已保存在本地提交 `4a4a8db`。本次不发布 GitHub Release。

## 已确认的问题与修正

- v1 全局 RBF 形变在膝、踝、肘附近的主方向缩放比例接近 2:1；改为分段适配，肢体横截面两个方向等比缩放。关节附近连续混合，躯干继续使用空间适配。
- v1 中指各节源关节经过几何拟合后，距对应魂指骨约 7.12 / 10.50 / 13.01 cm。v2 逐节对齐，掌面方向参与确定旋转，重算手指静态形状。
- v1 下颌几何仍在躯干形变区，头颈权重又存在突变。v2 下颌与头发共用头部等比变换，颈部权重连续过渡。
- 袖子与衣身在正面投影中重叠，不能仅用坐标阈值或未经清理的自动权重区分。v2 在腋下用网格连通性分离袖子与衣摆，并在肩部沿表面平滑过渡。袖口去除指骨影响；裙边、蝴蝶结与胸前挂件不随手臂移动。
- 保留发夹、光环、背包细化；模型仍为 66,678 三角面、264 骨、8 材质，最多 4 个顶点权重。

## 已做的检查

- Blender 的抬臂、屈膝、转头、垂臂和弯指诊断姿势；这些是人为设置的姿势，**未执行游戏动画**。
- 相同弯指姿势下，手部网格边长度比的第 99 百分位由 5.13 降至 1.33；最大值仍为 3.82，未将残余局部形变隐瞒为完全消失。完整数据见 pose-comparison.json。
- 37 个最终资源包通过独立 CUE4Parse 读回，保持游戏原生材质及真实 VT；核对外观表、隐藏部件、Skeleton、PhysicsAsset、PostProcessAnimBlueprint 引用。
- 最终 cooked 61,323 个渲染顶点对应全部 34,167 个源顶点；位置最大误差 0.000035286 cm，按 UE 权重量化规则复算后误差为 0。
- 骨架参考变换最大平移误差 0.003062 cm、旋转误差 0.013160 度。
- UE 导入仍出现 bind pose 重建提示；通过后续参考骨架与实际顶点/权重核对验证，未将该提示描述为没有发生。

## 安装与回退

本次安装已按以下流程完成：用户退出游戏并确认游戏进程已结束。将当时的 `z_Sui_HeiShang_JK_v1_P` 三件套备份到游戏目录外，再复制本包 `mods` 中 v2 的 `.pak/.utoc/.ucas`。不要叠放两个模型包。
现有 `z_Sui_Hun_NaturalVoice_Library_v3_P` 语音包保留。安装后记录三文件 SHA256，后续仍需结合用户反馈检查黑伤（逃亡）的待机、行走、跳攻、握武器和服装切换。
若有问题，退出游戏后撤下 v2 三件套并恢复备份。不改存档或清除缓存。

## 限制

这是一版待实测的修正候选，不能据离线预览保证所有游戏姿势。手臂紧贴身体的压力测试中仍有袖口/裙边穿插；新模型没有新增裙摆、头发或背包物理，也没有面部表情及额外 LOD。
