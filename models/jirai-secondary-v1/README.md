# 地雷岁裙摆与头发物理研究：未安装

此目录保存 R5 之后的隔离研究配方，不是发布或安装候选。吊带、铁扣和图集修复已拆入 `../jirai-detail-v1`。

实验包括前裙片按抬腿调整权重、扩大裙摆模拟空间、增加侧发独立模拟分区、按真实衣服网格校正初始间距，以及只用于 cloth 的球/胶囊碰撞。最终身体仍保留原 gameplay/ragdoll PA。作者自制蹲姿、跑步摆腿、抬头抬手动画用于离线测试，没有提取或分发原游戏动画。

仅通过粒子稳定性和静止轮廓检查不足以通过本研究。额外的编辑器辅助函数实际播放动画并执行 Chaos，再从最终 cooked 蒙皮和 GPU cloth 映射重建渲染表面，检查大腿/裙子及头发/衣服的边交叉。
