后续候选允许保留部分深蹲穿裙，不再把“所有交线为零”作为牺牲日常裙型的目标。不得降低粒子稳定、绑定误差或裆部覆盖检查阈值。最终需要独立容器读回、实际映射表面重建、连续走停恢复检查和人工离线审阅，再记录游戏实测的实际范围。

复查发现旧手工同步 helper 未消费组件初始化的 `ClothTeleportMode=TeleportAndReset`，原离线结果不能证明连续惯性或回落。新 helper 在无请求瞬移的输入中消费标记并记录请求/实际值，要求实际模拟值始终为 None。原 R7 失败记录和旧输出不删除、不改写成通过。

纯参数增强的组合仍出现局部折住，另加入可见裙面的量化混合上限。选取 `firm-compact`：重力 .3→1，恢复驱动 .01→.28、恢复阻尼 .6→.7、弯曲刚度 .15→.55、整体阻尼 .1→.15、局部阻尼 .25→.2、摩擦 .1→.05、移动继承 .6→.25、旋转继承 .5→.2；两个原 13 cm 的裙子专用大腿胶囊减至 9.5 cm，其他碰撞和头发参数保留。可见裙面物理混合上限为 **40%**，其余由原蒙皮维持裙型；这不是 0.4 cm 位移限制，MaxDistance 仍为 R7 的 48 cm。

25% 混合也试算过，但会让本模型较强的抬腿蒙皮占比过高，普通步行抬升反而未过门槛，没有选用。40% 试算通过后，必须重新 cook、在 native render section 和 GPU buffer 两处写入 uint16 混合值，独立解码并重建可见表面再验证，不能拿试算充当成品验证。

回落门槛预先固定：停下 2 秒内回到范围内，最后半秒的下摆抬升 p95≤1.5 cm、最大≤3 cm、位置残差 p95≤3 cm、速度 p95≤1 cm/s；普通步行全过程抬升 p95≤6 cm。骨骼蒙皮运动也包含在可见表面中。粒子边长比 .70–1.25、固定点 .03 cm、MaxDistance 超出 .15 cm、静态映射 .3 cm 和首个实际求解帧 .5 cm 的既有门槛保留。
