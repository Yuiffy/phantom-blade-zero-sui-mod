# 岁己 JK v11：袜口、裙色、手指与挂点细修

2026-11-15，PBZ build 26367565，成年魂「黑伤（逃亡）」。**已完成离线构建和最终容器核验，未安装、未游戏实测。** 当前已安装版本是 v10；用户试玩后提出本次细修。Reviewed v4 语音保持原样。

## 外观修改

- 从 v10 最终图集继续清理裙子全周的残留粉色，扩大到此前漏掉的低饱和色斑，保留原有白色下摆条纹和干净褶皱。此次裙面修补 120,488 像素；阈值检测和近景不是所有光照下绝无色差的证明。
- 移除猫脸袜原有三颗熔化凸块，按参考立绘重画两个三角猫耳、小圆眼与嘴；直接附着袜面，避免悬浮珠子和旧投影叠加。另一侧袜口重建平整边界，并清掉上方散乱粉色，保留连续吊带、羽翼和下方银扣。
- 沿原手指关节连线增加径向体积，最多约 2.55 毫米，不缩短手指、不移动骨骼、不改手部权重；掌根和袖口保持原位置，避免扩张时挤压拇指根短边。手指仍沿用现有网格，未重建指甲或所有手部拓扑。
- 猫挂件向背带贴近 2.2 厘米，修正整个挂环的位置，新增嵌入实际背带的短吊点和缝入耳后的小连接。金色爱心贴回蝴蝶结。挂件和吊点采用支撑三角面重心插值所得权重，避免依旧只跟随 spine_04 导致转身脱离。
- 按现有部件拆分马尾、头发、外套、裙子、书包、背带、袜面及挂饰的表面粗糙度，继续使用已验证的原生父材质；24 个身体材质槽共享同一张 4K 图集，不为每一槽复制 4K 纹理。此版本没有新头发着色器，也没有真正摆动物理。

## 离线检查

69,041 三角面、35,402 源顶点、264 骨，60 个资源包，无自制 shader。相对 v10，位置改动仅在手及挂件；权重改动仅在挂件。头颈、肩背、腿、裙子和书包几何/权重保持不变，UV 贴图有本次针对性修改。

人工每指节 35° 弯曲诊断：相同的 6,988 条手部边，p99 拉伸 1.2357 → 1.2449；超过 1.6 倍的边均为 4 条，最大值均约 3.19。体积调整未消除旧有掌根异常；这不是提取的游戏握持动画。支撑上身骨局部旋转 0/±30° 时，吊点截面中心至支撑面保持约 1.17–1.37 毫米的嵌入偏移。

独立读取最终 IoStore 后，80,990 个渲染顶点覆盖全部源顶点，位置最大误差 0.000035286 厘米；按安装 UE 的权重量化复算，误差为 0。核对原生叶子材质、VT、目标外观表与完整参考骨架；无解析器警告。编辑 PNG 与准备 RGBA 像素一致，实际 cooked VT payload 与最终容器逐字节一致；尚未独立将最终 VT 解码为像素。

## 动态进度与使用

`prepare_motion_source.py` 已在独立 `tripo-motion-v1` 目录生成马尾、挂件、裙摆、外套下摆和包体的低分辨率模拟壳、固定区及有限位移参数草稿。**未导入 UE、未模拟、未烘焙、未安装，不属于本 v11 成品。** 真实物理需要补齐兼容 MSVC 与 Windows SDK，且还须验证 PBZ 运行入口；不能把材质粗糙度当作物理。

Blend 内嵌最终图集。FBX 不嵌图，当前文件名引用 `sui-jk-albedo-v11.png`，外部软件可指定 `textures/` 下的 PNG。构建脚本依赖本机合法提取模板及工具；源代码在仓库的目录布局不同，运行前须调整同级 v10 基线、PBZ 根和工具路径。不是开箱即用工程。Blender 后台 CPU 两线程、BelowNormal；UE commandlet 单线程、BelowNormal。

本机 `variants/new-jk-v11/install-verified.ps1` 仅准备 v10→v11 的三文件替换、备份和哈希校验，未执行。安装须游戏退出；不能与其他模型候选叠装。模型容器及原始游戏资产只留本地；公开源模型、图集与角色形象不适用代码 MIT 许可，见 NOTICE.md。v10、v9、v8 和原始 Tripo ZIP 保留。
