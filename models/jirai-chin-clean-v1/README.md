# 地雷岁下巴方斑：缩小贴图串色修补

用户游戏截图显示下巴偏左有灰紫色方斑。源 PNG 与最高精度压缩图采样未显示同程度色块；独立读取实际安装 LashLip1 的 BC1 虚拟纹理 bulk，按其实际 dense Morton 布局还原第 0–6 级图像后，在第 4、5 级复现同部位灰紫色方块。图集碎片紧邻异色背景，较低精度过滤将异色带入皮肤。该证据支持贴图串色诊断，不代表原生 shader 与游戏全场景已复现。

本候选把下巴涉及的十六个原生 UV 碎岛，共 354 个顶点，移动到独立 1024² 空区中。每岛使用 256² 图块，表面距边至少约 48 像素，内部按原肤色采样，低于嘴部的位置渐进归一为原干净下巴肤色，未覆盖区以最近有效颜色填满。原有占用像素保持；所有顶点位置、切线、三角索引、权重、UV1、材质分区、骨架、布料与物理保持。已认可的眼眶、睫毛、虹膜、眼白、嘴角几何和上部睫毛 UV 不变。

工作途中本机安装集合更新了 Choker1 颈圈，并移出了另一个任务的 JKSkirt1。初稿未安装；当前候选以实际 Choker1 身体重新生成，保留完整新颈圈，沿当前安装集合核验，不重新安装已移出的裙摆候选。基线差异和旧构建留在私有归档。`zzzzzzzzzz_Sui_JiraiChinClean1_11_P` 合并身体、Skin 叶子 MI 与新 8K VT 三个 package，替换旧 LashLip1 与 Choker1 共六文件；保留其他十八文件的哈希。原生 skin shader 与其他参数完整保留，仅 Albedo 引用指向新图集。

本机顺序：`common.py` → `author.py` → `verify_geometry.py preflight` → `patch_native.py` → `cook_texture.py` → `package_candidate.py` → `verify_geometry.py` → `verify_mount.py`。`decode_vt.py before`、`after`、`verify` 从独立读回的真实 BC1 VT 分别解码并对比指定下巴区域的不同 mip。其解码只适用已检查布局，遇到其他格式会失败。不能作为通用 Unreal VT 解码器。

新版对应下巴区域的 mip4/mip5 相对最高级 RGB 偏差 p95 约为 3.0/3.6，旧版约 19.9/37.5。三方向近景检查通过。范围是截图所指下巴区域；极低精度下其他面部 UV 仍可能串色，不声明全脸全距离彻底解决。

`install.py` 默认预检，`--apply` 在游戏退出后备份并替换上述六文件。任何安装/实际读回失败均恢复安装前集合。`--rollback` 默认预检，配合 `--apply` 才回退。131 个保留有效资源的 metadata 和完整导出载荷逐项保持，实际安装再读回。未操作游戏、截图、录屏、删缓存或改存档。

截图、原资产、源与解码图集、失败/旧草稿、预览和容器均仅留忽略的 `private/jirai-chin-clean-v1/`。公开证据仅文字、数值与哈希。本次同步源码与数值证据，Release 未更新；新候选游戏观感尚待用户复试。
