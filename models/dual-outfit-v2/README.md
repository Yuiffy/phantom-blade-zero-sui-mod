# 双服装 v2

黑伤（逃亡）继续使用 JK 岁己 v4；黑伤及其内部无帽变体使用无棉花翅膀的地雷岁 R5。其他外观、图标、解锁规则和触发条件保持。独立语音包不变。

`build.py build` 以已验证 JK v4 与地雷岁 R5 为输入，克隆地雷岁身体到 JiraiOnly 路径并生成唯一合并外观表。`build.py gather` 独立读回最终容器，`verify.py` 对比全部 87 个非表资源的语义、载荷和两具模型骨架，检查 68 行外观表与三条目标选择链。

最终容器 88 包。JK cloth 为原来的五组，地雷岁为双马尾和裙摆三组，无棉花翅膀材质或模拟对象。

`install-verified.ps1` 只接受已核验制品，要求游戏退出、现用文件与构建前快照一致；备份当前双服装 v1 三件套到工作区后安装 v2，不叠装。失败时恢复旧包，保留语音哈希，并写安装凭据。

2026-11-16 已安装并核验哈希。旧 v1 的换装正常有用户反馈；v2 的真实游戏跑步、抬手与双手武器握持尚待检查。离线验证状态文件保留构建时含义，实际安装状态以 `private/dual-outfit-v2/installation-receipt.json` 为准。
