# 地雷岁 R5：比例、手部、肩袖和腿根修正，移除棉花翅膀

该候选基于原 R4 母版，保留解剖肩关节修正、原生骨名及角色独立 Skeleton。最终通过双服装 v2 包安装，不能叠装独立地雷岁包。JK v4、语音及服装对应关系保持。

作者代码 `author_revision.py` 从 `private/jirai-v1/sui-jirai-motion.blend` 重新生成源文件，不从已经调整过的结果重复累积形变。材质和 cloth spec 也以 R4 为基准读取。

- 上臂及前臂各缩短 6%，两段合计腕部位移约 3.62 cm；手、指、武器子骨及 IK 参考位置同步运输，武器子骨局部矩阵保持。
- 头部与头附属物下移 3 cm，颈中间关节下移 1.5 cm；布料头颈碰撞球和马尾固定区随之调整。
- 使用实际 JK v4 的原生关节对齐手部；`solve_hand_weights.py` 在既有骨骼归属内修正局部权重跳变，腕口两环共用手骨，避免手指拉开腕缝。未修改安装的 JK。
- 藏在裙内的高位腿根及内衬改为骨盆主导，减少上裙随腿摆动。
- 增加三角肌体积与袖壳间距，清理被袖壳遮盖的内层皮肤，补齐袖背的两个小开口。
- 删除 source_component 910、911、2003、2004 及对应材质、VT 和布料配置。仅保留双马尾和裙摆三组 cloth。

入口顺序：`run_blender.py author_revision audit_revision review_revision`，随后 `build_candidate.py`。手部参考提取与受约束权重修复的输入和结果在私人 diagnostic/JSON 中保留。`save_revision_review.py` 保存带隐藏导向网格的编辑母版，以及由最终 cooked 表面和真实离线 Chaos 样本重建的正背预览。继承目录内旧 wing/prepare_motion/finish_review 脚本不属于 R5 入口，不应运行。

最终独立读回：42 个独立地雷岁资源包、264 mesh 骨、13 个可见材质、55,286 可见三角面，含三组隐藏模拟网格共 59,342 三角面。源位置与最终 cooked 表面最大误差约 0.000036 cm，量化权重精确对应。完整原生 Skeleton 保留 1,134 骨；按骨名修改必要的 translation mode，没有覆盖游戏共享骨架。

检查范围：人工弯指、抬臂、迈腿；真实 UE 原始参考动画重定向；三组组件运动 Chaos 求解；最终 GPU cloth mapping、参考骨架、资源引用及 VT payload。常规每关节 35° 弯指无边长比超过 1.6 的边；70° 强弯曲 p99 约 1.553，仍有少数局部拉伸。四组迈腿诊断中，上方腿根采样点均在后裙内。肩袖采样接触显著减少，仍有近端局部接触，未证明所有动作无穿插。

这些是离线检查，不能代表全部奔跑、战斗、双手握持或过场表现。2026-11-16 用户认可整体质量并要求提交远端；同时报告深蹲/跑动大腿穿裙、一手握刀不贴合、左大腿后暗痕与吊带肉色凸起，希望侧发和马尾避衣物摆动。上述问题转入独立研究，R5 保留为回退基线。实际后续 JK-only 升级保持了全部地雷岁 R5 数据。
