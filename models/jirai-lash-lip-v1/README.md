# 地雷岁睫毛颜色与右嘴角修整

在用户认可继续细修的 Face2Hybrid1 组合上，把上睫毛、外眼角睫毛翼和四组下睫毛的原有灰白、粉色表面改为黑色。只修改这些表面的贴图采样，眼眶、睫毛几何、Face3 虹膜/瞳孔及闭合眼白均保留。原睫毛本身较厚，统一染黑会让原轮廓更明显；本轮没有改变其厚度和形状。

右嘴角原有两条浅折面在着色后形成分叉，单改贴图的初版对可见分叉几乎无效。最终把局部 72 个顶点的下方细小折面合到原上方嘴线上，最大只沿 Z 移动约 0.306 cm；左嘴角、嘴尖、其他脸部位置、全部三角索引和切线帧保持。局部三角面没有翻转或新增退化面，原拓扑和权重不变。

原图集包含复用颜色，直接染黑可能污染皮肤。作者脚本把涉及的原生 UV 小岛隔离到原 Skin UV 未使用的图集区域；其中两个较大的头部小岛使用局部 XZ 图块，按原 UV 采样烘焙原肤色，清理边缘空隙后再画睫毛。其他小岛复制原图块。原图集所有被旧 Skin UV 占用的像素保持原样，新的采样坐标只用于选定小岛。Normal、ARM、SCMT 均验证为常量图，因此 UV 移动不改变这些输入。离线预览经过检查以排查额头染黑和图块边缘串色，未通过的草稿从未安装。

候选 `zzzzzzzz_Sui_JiraiLashLip1_7_P` 仍只含身体网格、Skin MI 与新的 8K sRGB VT 三个 package。保留光环、袖内补面、头饰、服装图案、JK、裙摆物理及语音。原生字节修改只涉及限定嘴部 Z 坐标和选定 Skin UV0；骨架、分区、布料、物理、权重、UV1、索引和切线帧完整保留。

本机顺序：`common.py` → `author.py` → `verify_geometry.py preflight` → `patch_native.py` → `cook_texture.py` → `package_candidate.py` → `verify_geometry.py` → `verify_mount.py`。最终容器由 CUE4Parse、retoc、UAssetAPI 与 native reader 独立读回，核对黑色睫毛采样、嘴部范围和其他表面保护。隐藏 Blender 以两线程、低优先级作三方向近景检查，隐藏 UE 单线程导入和 cook。

`install.py` 默认预检，`--apply` 在游戏退出且所有门禁通过时备份并替换上一轮 Hybrid1 三件套，实际安装读回失败则恢复安装前集合。旧 Hybrid1 贴图随旧包退休，不作为保留资源要求；仍在使用的其他 102 个资源 metadata 另行比较。`--rollback` 默认预检，配合 `--apply` 可按凭据恢复前一组合。不启动、操作或关闭游戏，不截图、录屏、清缓存或改存档。

原资产、图集、失败草稿、预览和安装容器保留在忽略的 `private/jirai-lash-lip-v1/`。公开证据仅文字、数值与哈希。预览使用源 PNG，不能代替 cooked VT 解码、原生 shader 或实际游戏灯光；新候选游戏观感与动态表现待用户复试。没有提交、推送或更新 Release。实际安装状态见 `../../evidence/jirai-lash-lip-v1/README.md`。
