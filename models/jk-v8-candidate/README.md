## 处理依据与变化

- v7 的 component 25 是领结尾带，不是实际白衬衫领。白领、背心和肩部在主网格 component 0 内（见本机 v7-parts.png 的部件颜色检查）。这次按真实表面处理，不再只缩放领结尾带。
- 在 v6 重建时为每个顶点记录原始模型位置，核对与 v6 bound 模型逐点一致，再将此对应关系传给 v7。这让上身可以恢复原始模型中较小、较直的领口及窄肩轮廓，避免继续按男性骨架的空间笼横向拉宽。
- 上身使用源空间连续形变，肩部到袖子、胸部到下摆平滑过渡；头部主区横向约增加 13.2%、纵向约增加 5.3%，领结随上身重新定位。发顶高度保持一致。
- 同高对照中，发顶到脚底 23% 高度处的横向剪影宽度相对 v7 缩小约 13.1%。此测量包含袖根和附件，不是解剖肩宽；参考/v7/v8 的宽高比分别为 0.2188/0.2710/0.2354，尚不完全一致。
- 主衣服重新计算连续顶点法线；头部使用仿射变换的逆转置处理法线，减少变形后硬边。原材质、UV 和拓扑保持一致。
- 原版 264 骨的父级和参考矩阵逐项完全保留。手部、腿部、裙子、安全内衬和书包共 15,872 个受保护顶点的位置与权重和 v7 完全相同。原骨架和握点限制了袖子可收缩的范围，整身轮廓仍不是立绘的逐像素复刻。
