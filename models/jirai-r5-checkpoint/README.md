# 地雷岁 R5 可编辑检查点

2026-11-16 用户反馈：“现在地雷服质量不错哦，提交远端一版。”本目录保存当时无棉花翅膀的完整可编辑角色母版 `Sui_Jirai_R5_Editable.blend`，图集内嵌。模拟导向网格单独隐藏，普通编辑显示角色表面。文件大小和 SHA256 见 manifest.json。

对应安装组合是 `z_Sui_DualOutfit_JK5_JiraiR5_P`：黑伤（逃亡）= JK Motion v5，黑伤及其内部无帽变体=地雷岁 R5。JK-only 升级只替换 JK 身体和其 cloth PA；独立读取验证了地雷岁数据相对双服装 v2 仍一致。

R5 收短手臂与头颈，修复原生关节对齐的手部权重、腕缝、肩袖表面和高位腿根，保留双马尾及裙摆三组布料。最终地雷岁表面 55,286 可见三角面；mesh 264 骨，角色独立 native Skeleton 不覆盖游戏共享骨架。

用户同时明确报告这些待修问题：深蹲/跑动时大腿穿裙、希望侧发和双马尾有避开衣物的物理、单手未贴住刀柄、左大腿后侧竖向暗痕、左腿前吊带肉色凸起。它们属于后续独立实验，本检查点不宣称修好。见 `evidence/jirai-r5-dual-v2/runtime-feedback.json`。

制作代码位于 `models/jirai-proportion-v1`，最终双服装合并配方位于 `models/dual-outfit-v2`。完整原游戏模板、工具、密钥、私有中间数据和修改后游戏容器留本地，仓库并非一键重建环境。`blend` 中没有原版魂的可见表面或动画库；内容来源与许可范围见根目录 NOTICE.md。
