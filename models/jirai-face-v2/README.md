# 地雷岁 Face2：鼻侧眼白与刘海投影修整

根据 2026-11-17 用户实机近景及原始地雷服立绘修整。鼻侧除了新增的闭合眼白，原头部还存在位于其前方的旧眼窝表面，带着红黑色投影；单改眼球颜色不能覆盖它。此版把有限的鼻侧眼窝内部改成暖白，保留眼睑边缘、虹膜及原眼白几何。清理刘海上烘焙进去的眉毛、眼线和皮肤色，用同一片刘海较高处的干净颜色恢复银白发束与粉挑染；真正位于刘海后方的眉毛组件 101/102 原样保留。

UV 审计发现约 7309 个改绘位置也被衣服表面复用，因此不能直接覆盖共用的 `T_Jirai_Base`。成品只含三包：新建的 8K sRGB VT `T_Jirai_Face2`，以及 `MI_Jirai_Skin`、`MI_Jirai_Hair` 两个原生叶子材质。材质只换 Albedo 导入引用；其完整属性和 native 导出载荷逐字节保持，父级、法线、Mix、皮肤厚度、标量与 shader 均沿用已验证版本。其他表面继续引用原图，渔网袜及原共享图集不变。

补丁 `zzz_Sui_JiraiFace2_1_P` 独立于裙摆候选，不覆盖身体、骨架、布料、物理或语音包。数字 `_1_P` 提高补丁挂载顺序；已用 CUE4Parse 将当前 MOD 与补丁按两种目录顺序挂载，确认资源解析一致。安装前重新检查当前两项材质和原图集与基线相同。若后续版本修改了这些材质、头部 UV 或原图集，需要重做兼容检查。

本地流程：`inspect_surface.py` → `author_atlas.py` → `verify_surface.py` → `cook_texture.py` → `package_candidate.py` → `verify_mount.py`。`render_preview.py` 提供同几何、灯光和相机的正面与两侧对比；`save_editable.py` 保存正确分配两套图集的本地可编辑预览。安装脚本要求所有校验和人工预览检查通过、游戏退出，只新增三件套并核验原 MOD 哈希；不会启动、结束或控制游戏。

成品、原游戏模板、图集与角色母版只留 `private/jirai-face-v2`。公开代码不包含游戏资产、shader 或密钥；角色及图集遵循根 NOTICE.md 的边界，不适用代码 MIT 许可。离线预览不能代替 PBZ 原生材质、实际光照与运行测试；状态见 `../../evidence/jirai-face-v2/summary.json`。
