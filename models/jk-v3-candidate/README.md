# 岁己 JK v3：颈肩局部优化候选

日期：2026-11-15。目标：PBZ build 26367565，成年魂「黑伤（逃亡）」。
状态：v2 已安装并完成文件校验；本 v3 仅完成离线构建和核验，未安装、未游戏实测。

## 调整

- 在 v2 分段肢体适配基础上，将头部及头饰整体向下 3.5 cm、向后 0.6 cm，颈部连续过渡，缩短头肩视觉距离。
- 局部肩线最高抬升 4 cm，恢复上臂近端体积，并给肩部加入原版锁骨的渐变权重。保留原版 264 根骨骼及参考变换。
- 目标空间高度 130 cm 以下的 13,188 个顶点位置及权重与 v2 完全相同。
- 仍为 66,678 三角面、34,167 源顶点、8 材质；局部最多 5 个权重。无新增头发、裙摆、背包物理。

## 验证范围

- 同镜头比较 v2/v3 静态、转头、抬臂。预览使用人工诊断姿势，未执行游戏动画。
- 颈肩边长比：抬臂最大值 1.067 → 1.050；转头第 99 百分位 1.202 → 1.214、最大值 1.388 → 1.489。缩短颈部后的局部转头形变略增，不能宣称所有指标都改善。
- 独立读回最终 37 个资源，验证原生材质、VT、外观选择、隐藏部件、Skeleton、PhysicsAsset 和 PostProcessAnimBlueprint 引用。
- cooked 61,322 个渲染顶点对应全部 34,167 个源顶点；位置最大误差 0.000034571 cm，按 UE 权重量化复算后误差为 0。
- 骨架平移最大误差 0.003062 cm，旋转 0.013160 度。UE 导入仍有 bind pose 重建提示，以上检查核验了实际结果。

## 安装边界

目前实际安装的是 v2，旧 v1 已备份到游戏目录外。本候选包不自动安装。
后续替换需在游戏退出后按校验清单备份 v2 三件套，再安装 v3 三件套，避免模型包叠放。现有语音包继续沿用。
待用户实测待机、转头、走跑、跳攻和持武器动作；离线通过不能保证游戏所有姿势。
手臂紧贴身体时仍可能有袖口/裙边穿插；没有新增面部表情或 LOD。
