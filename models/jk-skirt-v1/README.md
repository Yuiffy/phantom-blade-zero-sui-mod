# JK 裙子避让实验

**性能回归，已回退：**2026-11-18 用户报告换装掉至约 9 帧。离线匹配测试确认 32/8 共享求解开销明显过高，五组布料求解中位数约 315.47 ms，对比 8/2 约 20.60/20.55 ms。未取得游戏 trace，不能断言该补丁是 9 帧唯一原因。已在游戏退出后按哈希归档原三件套，保留其他所有文件；禁止把旧稳定性门槛通过视为性能通过或重新安装授权。后续优化在 `models/jk-skirt-perf-v1` 隔离进行。

针对普通跑步大腿穿裙，参考地雷岁连续裙摆回落实验。2026-11-18 已安装 `zzzzzzzzz_Sui_JKSkirt1_9_P`，实际安装组合独立读回通过，原 21 文件哈希保留。候选在 `private/jk-skirt-v1` 隔离制作；[公开数值与安装证据](../../evidence/jk-skirt-v1/README.md) 不附游戏派生资产。尚待用户实机复试，Release 未更新。

保留最新已安装 JK 脸部、虹膜、贴图、原骨架、蒙皮、原生材质和 gameplay/ragdoll PhysicsAsset。只编辑裙子的物理资产、共享求解器、裙面位置及两处 GPU 布料映射；单独创建 cloth-only PhysicsAsset。对最新有效安装身体进行组合，避免覆盖其他会话的脸部修改。

原裙子物理 MaxDistance 约 0.627 cm，可见上段受原腿部蒙皮影响，单纯增加碰撞不能充分避让。选中方案把隐藏固定带从 113 cm 提到 120 cm、仅物理网格改为 pelvis 驱动、MaxDistance 放至 40 cm；使用两个较低位的大腿胶囊和 pelvis 球，避免上段碰撞把腰边挤住。可见裙面腰部渐变保持，宽度最多增加约 5%、前后深度约 12%，单顶点最大移动约 2.0125 cm。引擎原生投射后，裙面物理混合上限为 65%，减少碎褶，同时保留抬腿避让。GPU 分区和全局缓冲的两处完整 64 字节记录一起修改，原生顶点蒙皮与 UV 保留。

求解器为 32 次迭代、8 个子步，比试验中 10 个子步少 20%；这不代表游戏帧率提高 20%。JK 的五组布料共用求解器，四组其他布料的单独配置和物理资产保持。试验比较了更低求解量、碰撞、重力、回位驱动、按高度分配回拉力、隐藏固定带及导向网格；失败参数留在 private，不作为已通过候选。游戏性能仍待实际反馈。

`test_ue.py` 使用已修正瞬移重置标记的真实 Chaos 连续求解，三轮走动、慢跑、下蹲与完全停下，覆盖 30/60 Hz。输入是合成骨骼动画及组件移动，不是游戏实际动画。独立保留输入和输出哈希。先比较物理边长、固定点、位移限制，再从实际粒子输出和量化 native GPU 映射重建可见表面，检查回落及有外套遮挡判断的采样穿插。

门槛沿用地雷岁实验：物理边长比 .70–1.25，固定点误差 ≤.03 cm，MaxDistance 超出 ≤.15 cm；静态映射误差 ≤.3 cm，第一实际求解帧 ≤.5 cm。停下 2 秒内恢复；最后半秒下摆抬升 p95≤1.5 cm、最大≤3 cm、位置残差 p95≤3 cm、速度 p95≤1 cm/s。普通步行全过程抬升 p95≤6 cm。不能通过放宽这些门槛提升失败候选。

编辑器 helper 只用于作者工程，不进入游戏容器。`query_mapping.py` 在项目副本中调用引擎原生映射生成器，允许不改变物理测试输入而重新投射裙面。`compose.py` 保留原始未修改导出载荷，避免 JSON 往返丢失 OptionalProperty 类型。`package_verify.py` 将成品独立解包、解析并比较不在裙面位置/映射范围内的 native 字节和其他资源，使用 CUE4Parse 复查加载及覆盖优先级。最终表面验证应传入解包后真实身体 JSON。

retoc 转换需要完整依赖上下文：缺少原游戏依赖时，骨架、游戏 PhysicsAsset 和后处理会变成 UnknownPackage；只拿候选容器解包时也会丢自定义材质解析。因此读取最新身体时加入已有且逐文件验过哈希的 28 包原游戏参考容器；候选读回再提供不含 JK 身体的本地依赖容器。它们仅用于验证，严格排除在最终两包白名单之外。成品要求 NameMap、Imports、全部导出数据和保留 payload 精确匹配，拒绝 Unknown 引用；另外用真正游戏安装组合的 CUE 读回验证原骨架、原游戏碰撞、后处理和全部材质未改变，不以工具目录合并时的重复包选择代替有效挂载验证。

裙子补丁使用 `zzzzzzzzz_Sui_JKSkirt1_9_P`，与 JKFacePolish2_8 的当前脸部合并后覆盖身体路径，脸部材质和新图集仍取原补丁。后续脸部整身补丁必须从最新有效身体合并裙子数据，避免高优先级旧身体撤销本修改。`finalize.py` 冻结六组全身表面、独立读回、图像来源哈希和人工审阅，`--install` 才安装；安装读回失败时只移出这次新增三文件，保留其他会话的文件。深蹲穿插作为已知限制记录，不用“交线全为零”牺牲普通跑步裙型。

后台 Blender 使用 2 线程、低优先级；UE commandlet 使用 `-onethread`；不启动、控制或结束游戏，不截屏或录屏。游戏资产、原始贴图、预览、密钥和成品仅在忽略的 private 目录保存。不得把离线验证写成游戏内已修复。
