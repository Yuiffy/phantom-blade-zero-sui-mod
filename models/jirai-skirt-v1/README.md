# 地雷岁 R7：裙侧避让与连通安全裤

从 R6 SkinEyes1 几何母版隔离制作，最终合并当前已安装的 Fishnet1 8K 图集，目标是改善蹲下、斜蹲、弓步和跑步时的大腿穿裙。实际构建、检查和安装状态以 `../../evidence/jirai-r7-skirt/result.json` 为准；离线结果不代表游戏实测。

保留已安装 SkinEyes1 的原生皮肤材质与双眼白，以及 R6 的脸、比例、骨架参考、手部、贴腿吊带、金属扣和头发表面，保留当前 Fishnet1 8K 图集。只修改裙子下摆形状与蒙皮、裙子隐藏模拟导向以及安全裤；不添加翅膀。裙子使用独立的布料碰撞资源，身体原 gameplay/ragdoll PA 与头发碰撞资源沿用原设置。

裙摆从 z=122 cm 到 z=108 cm 渐进外张，最大径向增加 4 cm，腰口不动。保留蕾丝、装饰的拓扑和 UV；裙面法线按改形的 Jacobian 变换，其他保留表面另行检查法线编码误差。隐藏导向改为 17×36 的 612 点规则网格，保留外张的下口，避免旧导向把短前蕾丝误当作整圈下摆。

安全裤腰口位于 z=125 cm，收合髋部以藏在外裙与束腰内部，裤口仍为 z=103 cm。安全裤采用不透明黑色材质，裤底是一张连通的表面。拓扑检查要求只有一个腰口、两个裤口，没有额外洞口或非流形边；下部按大腿表面增加包覆余量，避免皮肤顶破裤面；上大腿被包覆处还使用相同黑色材质作为备份。姿势预览另行隐藏裙子，检查深蹲与弓步时的裤底、内侧和裤口。

物理导向的腰部固定区与可见裙片的混合区分开：导向从较高的腰口固定，避免抬腿碰撞体与固定粒子相互挤压；上裙面从 z=128 cm 到 z=122 cm 渐进过渡到布料，保留固定腰口，同时允许膝盖靠近腰部时上裙片避让。UE 重建会重新生成渲染混合权重，所以 `patch_render_mask.py` 在 cook 后按受限解析写入 render section 与 GPU buffer 两份 uint16 混合值，要求其他所有字节和导出长度不变，随后独立读回最终容器并检查静态映射与实际求解帧。对于少数三角形外推点，另外用实际静态重建误差限制混合贡献到 0.25 cm，避免为了修复这些点而把整片上裙面固定死。最终仍独立执行原有 0.3 cm 静态与 0.5 cm 首帧门槛。对本例导向内侧偏移 5–8 cm 的髋内封底渐进恢复原蒙皮，避免内部封底随外裙布料甩到大腿表面。封底的原蒙皮也按安全裤的连续髋腿混合更新，避免斜蹲时出现固定在骨盆上的硬片。外侧可见裙片继续参与物理。内部清理只删除完全被安全裤包住的多余三角面：每个三角形的三个顶点、三条边中点及中心均须在安全裤内至少 0.3 cm，且高度位于 110–124 cm。独立源检查对每个删除面重新验证，其他面维持原顺序与 UV。保留孤立的源顶点以避免重排来源索引；契约明确记录 used_vertices，最终重建只要求实际被面引用的可见顶点存在于 GPU 数据中。原始编辑器映射的待处理状态明确保留，不能拿它当最终通过。编辑器工具不进入 MOD。共享求解器的计算次数有所增加，游戏内性能仍需实际试玩确认。

验证顺序：

1. `run_blender.py author_revision verify_source verify_coverage`：作者母版、FBX、保留表面与骨架、裤底拓扑。
2. `prepare_pose_contract.py`：七组作者合成动作，不包含提取的游戏动画。
3. `build_editor_tools.py`、`build_candidate.py`：新导入、骨架适配、布料创建、真实 Chaos 输出、新进程保存重载、cook、独立容器解析、量化权重与 GPU 映射重建。
4. `run_blender.py render_articulation audit_suspender diagnose_contacts render_coverage render_rest`：重建后的动作表面与覆盖预览。`PBZ_ONLY_AUDIT=1` 只审计；`PBZ_RENDER_PROFILES` 控制渲染的动作。
5. `verify_eyes.py` 检查最终眼白闭合拓扑、head 权重和眼睑遮挡；`compose_dual.py`：必须通过全部门槛才合并当前 SkinEyes1 + Fishnet1 的 JK5 与 R7，并逐包独立验证保留内容。
6. `run_blender.py save_editable` 保存最新几何母版并内嵌已核验的 Fishnet1 8K 图集。预览也使用这一图集，记录其源哈希；合并时直接保留既有 cook 后 VT 载荷，并独立验证 8K、材质语义及 payload 哈希。
7. 合并后运行 `verify_material_contract.py` 检查原生材质虚拟纹理、颜色空间及皮肤厚度通道；游戏退出后运行 `install-verified.ps1`，备份旧三件套并核验新文件哈希。脚本不启动或结束游戏。

动作门槛要求固定粒子误差小于 0.03 cm、MaxDistance 超出量小于 0.15 cm，边长比保持 0.70–1.25；初始可见映射误差小于 0.3 cm，第一实际求解帧位移小于 0.5 cm。接触审计分别保留原始腿边/裙面交线和经过衣服、安全裤遮挡采样后的交线，不把二者混为穿模面积；64 个方向的有限射线采样也不代表所有游戏视角。

`preflight_shorts.py` 只用于试算新安全裤与上一轮布料帧的遮挡关系，不是最终通过凭据；最终必须重新构建、真实求解并从成品重建。

失败实验保留在本地 `private/jirai-skirt-v1/iterations`，不会因增加 MaxDistance 或求解次数而自动提升为安装版。游戏模板、密钥、工具二进制、中间容器和原视频仅留本地。可编辑角色母版及预览沿用根目录 NOTICE.md 的许可边界，不适用脚本的 MIT 许可。
