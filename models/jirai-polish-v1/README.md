# 地雷岁实机反馈修整 Polish1

根据用户提供的游戏截图，处理眼睛圆睁、脸部色块、嘴线生硬、光环扁斜及大臂到袖内露空。此前 Face3 的用户反馈是“眼睛虽然改进了，但有点可怕”，不能记为脸部观感已获认可。

眼部连同相邻皮肤、眼白与虹膜作局部渐变缩放，减少眼白露出；移除旧眼周的碎片面，在原生 Skin 分区内复用释放的槽位，以 724 个顶点和 1,413 个三角面重建两侧眼睑，并与原头部共用 61 条边。通过约束三角剖分保留外边界和闭合眼孔，再对眼周及相邻原皮肤作深度平滑，消除原有陡折；眼孔内缘保持固定，法线跨接缝连续过渡，重画细眼线。原眼白保留闭合拓扑，虹膜继续沿用 Face3 独立贴图。正面固定射线网格中可见眼白采样由 9,045 降至 5,706，虹膜由 18,296 降至 12,405；这是离线投影面积，不是游戏画面统计或主观观感结论。

原图集含烘焙的明暗和局部修补色差。本轮为 Skin 建立连续的头部平面图集，以干净肤色与轻微腮红替换旧图案；其他身体皮肤使用同一基础肤色。检查所有头部之外及跨图块的三角面只采到均匀肤色，避免新的脸部图案串到脖子和身体。材质保留已使用的原生皮肤 shader、Normal、Mix、SCMT 与散射参数。身体裸露皮肤也会变得更均匀，这是本轮实际范围。

嘴部保留 Face3 已连续的几何、内衬和切线帧，重新画较短、较淡、弧度较小的嘴线；没有原样恢复旧版存在裂缝的口腔结构。光环对照 JK 实际 native 几何拟合平面，将原来窄长的椭圆展圆并调整朝向，同时变换法线和切线。

大臂不是仅有贴图发黑：两侧皮肤各有上、下两圈断边。复用已隐藏的旧虹膜高光碎片槽，增加 67 个顶点副本与 67 个三角面，把四圈边界接成连续表面。新顶点逐点复制原接缝位置、切线与完整量化权重；独立读回核验，接缝在相同蒙皮变换下保持重合。仍需游戏动作检查袖子遮挡、内部拉伸及穿插，不能据此承诺全部动作无问题。

## 包与本机流程

候选 `zzzzzz_Sui_JiraiPolish1_5_P` 仅含三个 package：地雷岁身体网格、`MI_Jirai_Skin` 和 `T_Jirai_Polish1`。保留 Hairpin1、Face3 的虹膜和其他资源、Patterns1、R8、JK FaceShape1 及语音。公开代码依赖已有私人模板和本机工具，不能仅用公开仓库重建。几何作者脚本还使用本机 NumPy、SciPy、Shapely 2.1（约束三角剖分）、Pillow 和 OpenCV。

1. `common.py` 冻结安装快照及用户反馈。本轮期间检测到新增 JK FaceShape1；核对其安装凭据、三个文件和仅覆盖 JK 的清单后，保留原十五文件并更新为十八文件基线，记录原快照。
2. `author.py` 创建局部几何、图集与明确的原生槽位选择；`verify_geometry.py preflight` 检查表面保护、蒙皮复制位置、断边闭合、眼部投影、UV 图块和光环。
3. `patch_native.py` 对冻结的 Hairpin1 原生载荷作限定字节修改。只改位置、切线、Skin UV0、选定索引槽，以及 67 个臂部副本和 724 个眼睑顶点的权重；臂部逐点复制对应接缝，眼睑复制原有头部刚性权重。UV1、骨架、分区、布料映射、物理和其他字节保持原样。已复用的旧碎片槽不能再按旧来源编号解释为原几何。
4. `cook_texture.py` 隐藏、单线程运行 UE；`package_candidate.py` 白名单打包。CUE4Parse 核对 metadata 与 VT，retoc 重新提取完整上下文，UAssetAPI 和独立 native reader 核对实际位置、切线、UV、索引和权重。
5. 顺序运行 `verify_geometry.py`、`verify_mount.py`，核对两个目录顺序及所有保留的有效 package。`run_blender.py render_review.py` 从最终容器读回几何渲染七个视角；图像清单绑定实际输入哈希，逐图审阅记录在私人 `visual-review.json`。
6. `install.py` 默认只读门禁，`--apply` 在游戏退出且全部哈希一致时只添加三件套。随后 `verify_mount.py installed` 再次提取实际安装集合验证载荷。`install.py --rollback` 默认预检，加 `--apply` 只移出本轮三件套；后续安装发生变化时停止。
7. `collect_evidence.py` 输出纯数值、反馈文本和哈希到 `evidence/jirai-polish-v1/`。本地参考、源图集、预览、游戏资产与容器留在忽略的 `private/jirai-polish-v1/`。
