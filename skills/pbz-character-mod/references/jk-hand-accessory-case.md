# JK v9：手指转轴、吊带和饰件

2026-11-15，PBZ build 26367565，成年魂黑伤（逃亡）。本页记录离线候选；不是游戏实测成功案例。源文件及数据见 `models/jk-v9-candidate` 和 `evidence/jk-v9-offline`。

## 手变短、弯曲时扭成一团

先查表面和原骨骼转轴的位置关系，再调权重。v7/v8 的上身横向收窄也影响了手及袖口，手指骨的参考位置仍属于原游戏骨架。与保留转轴对齐的 v6 对照，手表面最多偏移约 5.65 cm；直接给偏离转轴的表面重新分配权重不能恢复合理关节位置。

v9 恢复 2,342 个手部顶点及其 v6 权重，远端袖口用连续过渡恢复 568 顶点，避免修好手后袖口与手腕脱节。头颈、肩和上身继续保留 v8 的形状，骨名、父级与参考矩阵逐项不变。

同一人工每指节 35° 弯指姿势中，6,988 条手部边的长度比 p99 从 2.431 降至 1.236；超过 1.6 倍的边从 576 条降至 4 条。最大值仍有约 3.19，不能声称所有手指/握持动作都完美。此统计说明这一次表面恢复有效，不证明其他模型必须恢复 v6，更不是游戏动画验证。

## 多余吊带与袜口部件悬空

检查连通组件和实际权重。本次原 Tripo 模型已有大腿贴图吊带，另有一条 72 顶点/140 三角面的重复条带，全部跟随 pelvis；分腿姿势中它会单独挂在两腿中间。v9 删除重复条带并在大腿表面恢复一条连续吊带。保留的右袜小饰件重新绑定 thigh_r，左袜无参考依据的三颗凸点随翼饰重建移除。

不能把所有细条都一律绑定骨盆，也不应仅凭它在静态正面图中位置正确就通过。对绑带两端、承载表面和相邻骨骼分别检查；贴腿效果可以使用表面图集或适当的连续权重，不必为了“裙子材质”引入未经验证的新布料系统。

## 贴图串色和重建饰件

先在离线原图集上确认斑块是否已经存在。本次裙子粉色、外套背部书包投影和猫挂件背后的投影都存在于 Tripo 图集。按三角面 UV 所属和三维表面位置修复；材质索引必须参与筛选，不能让纯色饰件占用全幅方形 UV 后误选整个图集。

新羽翼和金心替换旧的模糊装饰，整组跟随 thigh_l。猫挂件的头、身体、蝴蝶结、耳内和五官统一跟随 spine_04；初次预览的颈部空隙和小身体被用户指出后，增大身体、上移蝴蝶结并加入连接颈部。细节好看不能替代整体比例检查，重建后要看近景、整身和不同姿态。

替换立体部件后还要清理它在底层表面留下的旧颜色。袜口上方的旧凸点/翼饰投影在新饰件出现后仍像杂乱三角碎片，须一并整理深色袜口和粉色横带。对补色边缘做适量过渡，再将颜色补入未被其他表面占用的 UV 间隙；不要直接全图膨胀涂色覆盖其他岛。本次补边半径 4 像素是此图集的选择，不是通用常数。

## 检查修复边界和最终烘焙

为保留顶点记录旧版索引，新增饰件用独立来源 ID。逐点/逐面验证保留几何、UV、材质、权重与骨架，并单独验证新增饰件的坐标范围和骨骼归属。拓扑变更后不能继续使用旧三角面数或简单通过降低断言要求放行。

新增象牙白仍使用已验证原生父材质的叶子 MI，重新 cook 为 VT。核对编辑图集、准备的 RGBA 像素、实际导入尺寸/VT 标志，以及新 cooked payload 与最终容器是否逐字节相同。没有将最终 VT 独立解码为像素时应明确说明。独立读取最终 cooked 蒙皮，复现安装 UE 的量化规则，而不是任意放宽权重误差。

v9 完成离线最终容器与蒙皮核验：69,117 三角面，35,459 源顶点，264 骨、10 材质、43 包。未安装；保留当前安装模型和语音，不能把预览、离线检查与用户游戏实测混为一谈。

## v10：右臂抬起时背部尖折、白色露出和包内投影

用户在长柄防御中观察到右背尖折及白衬衣色块。先将材质颜色、表面形状、蒙皮和真实层间穿插分开验证；仅凭截图的白色不能断言存在独立衬衣穿模。

旧 v8 脚本先使用已有袖子来源字段，再按离臂章的欧氏距离覆盖上臂权重。衣身和臂章静态相邻，部分来源袖子权重为 0 的衣身顶点却得到 0.6–1.0 上臂权重；相邻衣身几乎不跟手臂动。不要用未区分表面归属的空间距离覆盖可靠的部件来源；KDTree 本身不理解衣身、袖子和附件。

v10 保留 v9 检查点，按原袖子/衣身来源字段恢复右腋下的连续权重，并将错误袖笼分类拉出的衣身点恢复到既有躯干轮廓。存储后超过 1e-6 cm 的位置变化为 221 顶点，权重变化为 239 顶点；最大位置回移 10.60 cm。骨名、父级、参考矩阵、拓扑、UV、材质索引完全不变；变化仅限右侧近端衣身。所有顶点来源须经 `v8_vertex_index` 映射，删除饰件后不能把 v9 索引直接当作 v8 索引。

同一区域 11,096 条边，在两组人工抬臂姿势中，前举 p99 拉伸 1.561→1.136，高举 1.706→1.160；超过 1.6 倍的边 104→3、122→6。各版以自己的静止边长作分母，且同时修改了几何与权重，不能据此声称权重是唯一影响因素。这些不是提取的游戏防御动画，仍需游戏实测，不能承诺所有动作无穿插。

右背/侧面另有烘焙进图集的白灰与蓝色投影，按所属三维表面局部补色。书包朝向身体的一面混入一大片衣服投影：仅按蓝色阈值清理会保留粉色和黑色的脏轮廓。应隔离书包显示内侧，按面板归属整体修补；本次用干净粉色包边样本的中位色恢复内侧，避免最近邻多种边缘颜色产生大块三角/Voronoi 色差。保持外侧图案和几何不变，之后再检查整身及抬臂近景。
