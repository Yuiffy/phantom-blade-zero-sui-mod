# 成年魂原声语音替换

当前成功案例为 build 26367565 的 `library-natural-voice-v3`，2026-11-15 获用户总体确认。方法和证据边界见 [原语言库替换案例](voice-library-case.md)。v1/v2 的事件局部封装未解决用户报告的问题，以下明确保留其历史背景。

## 音源

优先按已有按钮标签和历史字幕定位；记录来源文件哈希、采样区间、处理参数。字幕中的“哼”“哈”或 UNKNOWN 不证明说话者身份。不要把待听审候选写成已确认的干净语音。

本次 v3 使用 30 段既有自然录音活动区间，48 kHz、mono、PCM16 中间 WAV，完整活动区间、衰减和短淡入淡出；没有目标时长强裁、TTS、CosyVoice、变声、新 ASR 或分离。FFmpeg 若需重做，单线程、低优先级，遵守游戏运行期间的资源限制。这是本次用户选择，不是所有语音任务必须禁用生成的通则。

原录播较大时使用已有索引或有读取预算的时间戳定位，不为几百毫秒语音解码整场录像。

## Wwise 格式与封装

本次解析了 42 个成年战斗事件，v1 选 22 个、v2 选 26 个、v3 选 27 个。通过真正的 EventID、MediaID 和语言库解析，中文媒体大多在外部 VO_CN 中。仅检查这些事件不能声称扫描了全游戏共享关系。

v1/v2 历史方案把对应中文非流式资源从 `External=4` 转为事件局部 `BulkData=3`；保持 EventID、LanguageID、SoundBankID、MediaID、HIRC IDs、CacheID、packaged Hash、插件/stream 类型及原生 duration/attenuation。英语和共享 VO_CN 不变。它们通过离线读回和安装哈希检查，但用户仍听到男声，不能作为运行成功方案复用。

v3 保留事件的原 External/BulkData 组织，替换 VO_CN/VO_EN 实际非流式载荷及六个原本嵌入的事件。保留完整原 bulk 前缀并按资源对齐要求追加载荷，仅更新目标 DataResources 的偏移/尺寸和 bank 对应 source 的 in_memory_size。保留原生 IDs、hash、顺序、索引及流式/prefetch 布局；这些是本 build 的已核验约束，不能把偏移当通用格式。

使用真实 Wwise Vorbis 编码器（本次 wav2wem v0.1）生成 WEM，再用独立 vgmstream r2168 解码。WAV 改扩展名不是 WEM。核验 RIFF、codec、采样率、样本数、峰值、解码相关性/SNR。候选超过原媒体或事件窗口时选其他完整活动段；若仍保留原声，应明确计为覆盖缺口，不能称随机池完整替换。

替换媒体时同步修正 bank 内对应源媒体大小及目标 DataResources 的 SerialOffset/SerialSize/RawSize。bulk flags 和 native 索引表须与实际加载策略相符；v3 保留它们的原生布局，不沿用 v1/v2 转为局部资源时的重建方法。按实际结构定位字段，禁止裸字节搜索后无条件替换。

最终容器解包后：逐项比较原生事件属性、ID、各语言、bulk 范围、bank 修改位置和媒体字节。v3 额外核验精确 8 资产白名单、完整原库 bulk 前缀、未修改资源映射、实际原引用到替换媒体的解析，以及 42 个已检查事件内共享媒体一致性。英语也有替换，不能沿用 v1/v2 的“英语不变”验收项。仅源 JSON 自检不够。

## v1 历史实验与验收

22 个事件涉及 206 个独立中文 MediaID，其中 109 个替换、97 个保留；17 个候选来自 10 份原录音。17 个编码独立解码相关性 >0.98、SNR >18 dB。此阈值是本次质量检查，不等于人工听审。

语音共用成年魂事件，因此会影响其他服装，剧情对白和最短攻击等未替换。模型仍只在黑伤（逃亡）。两个模块独立安装回退。

验收顺序：先试听音源/编码对照、确认说话者与背景；游戏中文语音中手动触发轻重攻击、受击、哼声等，检查无静音/截断/延迟/重复异常，再重启确认缓存；记录具体触发的事件。用户总体反馈不能补全未触发事件。若语音引入故障，先只撤语音三件套，保留已通过的模型。

公开发布音频前明确音源范围与权利；本次只公开方法和无音频的来源索引，原录播、按钮文件和游戏原声留在本地。

2026-11-14 后续：v1 暴露跳攻覆盖缺口，v2 补齐五组空中事件但用户仍报告轻击/跳攻男声，见 [跳攻漏项案例](voice-jump-case.md)。v3 覆盖 27 个所选事件所有现存随机媒体，中文 238、英语 236 个；30 个候选独立解码相关性 >0.98、SNR >18 dB，旧 134 个中文 WEM 字节保持一致。2026-11-15 用户确认本轮修复生效；逐段听审、逐武器和双语游戏验收未单独完成。

游戏配置与用户所选语言矛盾时保留两者，不能据配置断言实际播放英语。v3 没改语言设置，静态双语覆盖不等于双语运行通过。组合修复成功也不能单独证明库缓存优先级。含大量原版语言库数据的 v3 容器仅留本地，不作为公开语音包发布。
