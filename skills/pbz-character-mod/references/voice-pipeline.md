# 成年魂原声语音替换

## 音源

优先按已有按钮标签和历史字幕定位；记录来源文件哈希、采样区间、处理参数。字幕中的“哼”“哈”或 UNKNOWN 不证明说话者身份。不要把待听审候选写成已确认的干净语音。

本次仅用既有岁己按钮原声，48 kHz、mono、PCM16 中间 WAV，完整活动区间、衰减和短淡入淡出；没有目标时长强裁、TTS、CosyVoice、变声、新 ASR 或分离。FFmpeg 若需重做，单线程、低优先级，遵守游戏运行期间的资源限制。这是本次用户选择，不是所有语音任务必须禁用生成的通则。

原录播较大时使用已有索引或有读取预算的时间戳定位，不为几百毫秒语音解码整场录像。

## Wwise 格式与封装

本次发现 42 个成年战斗事件；22 个进入候选。通过真正的 EventID、MediaID 和语言库解析，中文媒体大多在外部 VO_CN 中。仅检查这些事件不能声称扫描了全游戏共享关系。

候选方案把对应中文非流式资源从 `External=4` 转为事件局部 `BulkData=3`；保持 EventID、LanguageID、SoundBankID、MediaID、HIRC IDs、CacheID、packaged Hash、插件/stream 类型及原生 duration/attenuation。英语元数据及 payload 不变，不改共享 VO_CN 文件。缓存标识保留后的运行时优先级仍需游戏实测。

使用真实 Wwise Vorbis 编码器（本次 wav2wem v0.1）生成 WEM，再用独立 vgmstream r2168 解码。WAV 改扩展名不是 WEM。核验 RIFF、codec、采样率、样本数、峰值、解码相关性/SNR。原候选长度超过所替换媒体或事件窗口时，保留原声。

替换媒体时同步修正 bank 内对应源媒体大小、每项 DataResources 的 SerialOffset/SerialSize/RawSize、bulk flags 和 native 索引表。按实际结构定位字段，禁止裸字节搜索后无条件替换。

最终容器解包后：逐项比较原生事件属性、ID、语言、bulk 范围、bank 修改位置和媒体字节；英语/未替换中文 byte-identical。仅源 JSON 自检不够。

## 当前实验与验收

22 个事件涉及 206 个独立中文 MediaID，其中 109 个替换、97 个保留；17 个候选来自 10 份原录音。17 个编码独立解码相关性 >0.98、SNR >18 dB。此阈值是本次质量检查，不等于人工听审。

语音共用成年魂事件，因此会影响其他服装，剧情对白和最短攻击等未替换。模型仍只在黑伤（逃亡）。两个模块独立安装回退。

验收顺序：先试听音源/编码对照、确认说话者与背景；游戏中文语音中手动触发轻重攻击、受击、哼声等，检查无静音/截断/延迟/重复异常，再重启确认缓存；记录具体触发的事件。用户总体反馈不能补全未触发事件。若语音引入故障，先只撤语音三件套，保留已通过的模型。

公开发布音频前明确音源范围与权利；本次只公开方法和无音频的来源索引，原录播、按钮文件和游戏原声留在本地。
